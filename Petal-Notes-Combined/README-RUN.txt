# Petal Notes — Combined Project

This folder keeps the original frontend and backend in separate folders.
Their source files and existing configuration have been copied without editing them.

## Run the backend
1. Open a terminal in `backend`.
2. Run `npm install` if dependencies are not installed.
3. Run `npm run server` (or use the start script listed in `backend/package.json`).

## Run the frontend
1. Open a second terminal in `frontend`.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite (usually http://localhost:5173).

Keep your existing backend `.env` file private. The MongoDB URI and other secrets
were preserved exactly as supplied; do not share this ZIP publicly.
